# 복명초 탐정단: 사라진 발표회 악보

6학년 음악 — **음표·쉼표의 길이 + 바장조** 복습용 모둠 추리 게임.
모둠 태블릿에서 각자 속도로 음악 문제를 풀어 단서 13개를 열고, 범인을 지목합니다.

## 수업 진행 (40분)

| 단계 | 시간 | 내용 |
|---|---|---|
| 도입 | 5분 | 타이틀 → 모둠명 입력 → 스토리 컷 → 탐정단 소개 |
| 추리 | 25분 | 단서 보드에서 문제 13개 풀기 |
| 지목·결말 | 5분 | 범인 지목 + 근거 3가지 + 악보 위치 → 결말 |
| 정리 | 5분 | 이미지로 저장 → 패들렛 제출 |

- 오답 1회 → 힌트, 2회 → 30초 잠금 (모둠 간 속도 차 완화)
- 단서를 **8개 이상** 열어야 «범인 지목» 버튼이 열립니다
- 모둠명·열린 단서·시도 횟수·서술 답은 브라우저에 자동 저장 → **새로고침해도 유지**
- 결과 화면 상단의 «처음부터» 버튼으로 초기화 (다음 반 수업 전에 누르세요)

## 교사 모드

주소 뒤에 **`?teacher=1`** 을 붙여서 열면 (`.../index.html?teacher=1`)
결과 화면 맨 아래에 그 모둠이 쓴 근거의 결정적/연막 단서 포함 여부가 한 줄로 표시됩니다.

- **학생 화면과 저장 이미지에는 나오지 않습니다.**
- 모둠 태블릿에 다가가서 주소 뒤에 `?teacher=1` 만 붙이고 새로고침하면 그 모둠 기록 그대로 보입니다
  (기록은 그 태블릿 브라우저에 저장되므로 교사 기기에서는 보이지 않습니다).

정답표·채점 기준은 이 저장소에 없습니다. 선생님 PC의 `교사메모.md` 를 보세요
(`.gitignore` 에 걸어 두어 깃허브에 올라가지 않습니다).

## 정답 노출 방지

문제 13개의 정답은 `index.html` 안에 글자 그대로 있지 않습니다.
문제마다 다른 소금값을 섞은 해시(`key`)만 저장하고, 학생이 적은 답을 같은 방식으로 해시해서 비교합니다.
소스 보기를 해도 정답은 읽히지 않고, 같은 답을 가진 문제끼리도 해시가 달라 패턴이 드러나지 않습니다.

다만 **스토리·단서 설명·결말 대사는 그대로 읽힙니다** (화면에 표시해야 하는 글이라 숨길 수 없습니다).
소스를 끝까지 읽으면 범인이 쉼표라는 건 알 수 있습니다 — 13문제의 답은 알 수 없습니다.
