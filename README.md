# 복명초 탐정단: 사라진 발표회 악보

6학년 음악 — **음표·쉼표의 길이 + 바장조** 복습용 모둠 추리 게임.
모둠 태블릿에서 각자 속도로 음악 문제를 풀어 단서를 열고, 범인을 지목합니다.

## 수업 진행 (40분)

| 단계 | 시간 | 내용 |
|---|---|---|
| 도입 | 5분 | 타이틀 → 모둠명 입력 → 스토리 컷 → 탐정단 소개 |
| 추리 | 25분 | 무작위로 나오는 문제를 풀어 단서 8개 이상 열기 |
| 지목·결말 | 5분 | 범인 지목 + 근거 3가지 + 악보 위치 → 결말 |
| 정리 | 5분 | 이미지로 저장 → 패들렛 제출 |

- **문제는 고를 수 없습니다.** «수사 시작»을 누르면 60개 은행에서 무작위로 한 문제가 나옵니다
- 난이도 3단계 각 20문제 — 단서 1~4번째 **하(★)** / 5~8번째 **중(★★)** / 9~12번째 **상(★★★)**
- 한 판에 보는 건 레벨당 4문제뿐이라, 옆 모둠과도 다음 반과도 나오는 문제가 다릅니다
- 오답 1회 → 힌트, 2회 → 30초 쉬고 **다른 문제**로 교체 (한 문제에 갇히지 않도록)
- 단서를 **8개** 열어야 «범인 지목» 버튼이 열립니다 (전체 12개)
- 모둠명·열린 단서·시도 횟수·서술 답은 브라우저에 자동 저장 → **새로고침해도 유지**
- 결과 화면 상단의 «처음부터» 버튼으로 초기화 (다음 반 수업 전에 누르세요)

## 우리 반 AI 게임 아케이드 (`arcade.html`)

학생들이 포스터를 보고 AI로 만든 미니게임을 모아 보여 주는 갤러리입니다.
탐정단 게임과는 **별개로 돌아가는 독립 페이지**라, 서로 영향을 주지 않습니다.

주소: `https://nuno4623.github.io/bokmyeong-detective/arcade.html`

- 카드를 누르면 게임이 iframe 안에서 바로 실행됩니다 (`sandbox` 적용)
- «내 게임 등록하기» → 이름·학급·제목·포스터·게임 파일을 넣으면 목록에 추가
- 게임은 **AI가 준 `.html` 파일을 그대로 올리면 됩니다** (칸에 끌어다 놓아도 되고,
  예전처럼 코드를 붙여넣어도 됩니다). 파일 안의 `<title>` 을 제목 칸에 자동으로 채워 줍니다
- 장르 필터 / 검색 / 정렬(최신·좋아요·플레이) 지원
- 포스터 사진은 올릴 때 자동으로 줄여 담습니다 (태블릿 사진 그대로 올려도 됩니다)

### 작품 보관소 연결 — 한 번만 하면 됩니다 (약 5분)

연결하면 학생이 올린 게임이 **선생님 구글 스프레드시트에 저장**되어
모든 기기에서 똑같은 목록이 보이고, 새로고침해도 남습니다.

1. 구글 스프레드시트를 새로 만듭니다 (예: "우리 반 게임 아케이드")
2. **확장 프로그램 ▸ Apps Script** 를 열고 `arcade-apps-script.gs` 내용을 붙여 넣습니다
3. **배포 ▸ 새 배포 ▸ 웹 앱**, 액세스 권한은 **모든 사용자**
4. 나오는 `.../exec` 주소를 `config.js` 의 `ARCADE_URL` 에 붙여 넣고 커밋·푸시

자세한 순서는 `arcade-apps-script.gs` 맨 위 주석에 그대로 적어 두었습니다.

**어느 스프레드시트에 쌓이는지**는 상황에 따라 자동으로 정해집니다.

| 스크립트를 만든 곳 | 쌓이는 곳 |
|---|---|
| 스프레드시트의 확장 프로그램 ▸ Apps Script | 그 스프레드시트 |
| script.google.com (새 프로젝트) | 드라이브에 «우리 반 게임 아케이드 (작품 보관소)» 를 자동 생성 |
| 쓰던 시트를 쓰고 싶을 때 | 스크립트 속성에 `SHEET_ID` = 시트 주소의 가운데 긴 문자열 |

지금 어느 시트에 쌓이는지 확인: 배포 주소 뒤에 **`?mode=info`** 를 붙여 열면 링크가 나옵니다.
**탐정단 모니터링(`apps-script.gs`)과는 다른 스프레드시트·다른 배포입니다.**
스크립트 하나에 접수창구(`doGet`/`doPost`)는 하나씩만 둘 수 있어서 그렇습니다.

연결 상태는 아케이드 화면 위쪽 띠에 그대로 표시됩니다
(초록 = 연결됨 · 노랑 = 아직 연결 안 됨 · 빨강 = 연결 실패).

**연결하지 않아도 페이지는 돌아갑니다.** 다만 올린 게임이 그 태블릿 안에만
저장되어 다른 기기에서는 보이지 않습니다.

### 관리자 모드 — 화면에서 바로 지우기 (선생님용)

주소 뒤에 **`?admin=암호`** 를 붙여서 열면 카드마다 «🙈 숨기기»·«🗑️ 삭제» 버튼이 생깁니다.

```
https://nuno4623.github.io/bokmyeong-detective/arcade.html?admin=내가정한암호
```

**암호는 한 번만 정해 두면 됩니다.** Apps Script 편집기에서
⚙️ 프로젝트 설정 ▸ 스크립트 속성 ▸ 속성 `ADMIN_KEY` / 값 `내가정한암호` → 저장 → 다시 배포.
(자세한 순서는 `arcade-apps-script.gs` 맨 위 주석에 있습니다.)

| 버튼 | 하는 일 |
|---|---|
| 🙈 숨기기 | 학생 화면에서 사라집니다. **되돌릴 수 있습니다** — 수업 중 급할 때 이걸 쓰세요 |
| 👀 다시 공개 | 숨긴 작품을 되돌립니다 |
| 🗑️ 삭제 | 시트에서 완전히 지웁니다. 되돌릴 수 없어 한 번 확인을 묻습니다 |
| 숨긴 작품 보기/가리기 | 내려 둔 작품을 관리자 화면에서만 같이 볼지 |
| 끄기 | 관리자 모드 종료 |

**안전장치**

- 암호는 **저장소에 올라가지 않습니다.** 선생님 Apps Script 안에만 있습니다
- 숨김·삭제는 **서버가 암호를 확인한 뒤에만** 처리합니다.
  브라우저에서 버튼을 흉내 내도 암호가 없으면 아무 일도 일어나지 않습니다
- 주소창의 `?admin=암호` 는 페이지가 열리자마자 **자동으로 지워집니다**
  (수업 중 화면에 띄워도 암호가 노출되지 않습니다)
- 탭을 닫으면 관리자 모드가 풀립니다
- 암호를 바꾸려면 `ADMIN_KEY` 값만 고치고 다시 배포하면 됩니다

`ADMIN_KEY` 를 정해 두지 않으면 **아무도** 지울 수 없습니다 (서버가 전부 거절합니다).

### 시트에서 직접 관리하기

관리자 모드 대신 스프레드시트에서 해도 됩니다.

| 하고 싶은 것 | 방법 |

## 모둠 진행 상황 모니터링

`teacher.html` 을 열면 모든 모둠의 진행 상황이 한 화면에 나옵니다.
도움이 필요한 모둠(멈춤 → 막힘 순)이 맨 위로 올라오고, 5초마다 자동 갱신됩니다.

| 보이는 것 | 설명 |
|---|---|
| 참여 모둠 / 사건 해결 / 평균 단서 / 도움 필요 | 학급 전체 요약 |
| 모둠별 진행바 | 연 단서 수 (n/12) |
| 상태 | ✅ 해결 · 🎯 지목 n회 · ⏳ ○○번 막힘 · ⚠️ n분째 멈춤 |
| 마지막 활동 | 마지막으로 뭔가를 한 시각 |
| 지금 막혀 있는 문제 | 어떤 문제에 몇 모둠이 걸려 있는지 |

같은 문제에 두 모둠 이상이 걸리면 «전체 지도 권장» 딱지가 붙습니다.
그때는 개별 지도 대신 칠판에서 한 번 짚어 주시면 전체가 같이 넘어갑니다.

**쓰려면 한 번만 설정하면 됩니다.** `apps-script.gs` 맨 위 주석의 순서를 따라
구글 스프레드시트에 Apps Script를 붙여 넣고, 나오는 주소를 `config.js` 에 적으면 끝입니다. 약 5분.

설정하지 않아도 게임은 그대로 돌아갑니다 — 모니터링만 꺼져 있는 상태입니다.

**알아 두실 것**

- 모둠명이 곧 식별자입니다. 모둠명이 겹치면 한 줄로 합쳐지니 겹치지 않게 안내해 주세요.
- 기록은 **선생님 소유의 구글 스프레드시트**에만 저장됩니다. 모둠명과 진행 상황, 그리고
  나중에 채점하실 때 쓰시라고 근거 3줄·악보 위치도 시트에 같이 남습니다 (모니터링 화면에는 안 나옵니다).
- `teacher.html` 도 공개 주소라 링크를 아는 사람은 볼 수 있습니다. 학생에게 알려주지 마세요.
  (모둠명과 진행률뿐이라 개인정보는 없습니다.)
- 수업이 끝나고 기록을 지우려면 스프레드시트에서 헤더 아래 행을 지우면 됩니다.

## 정답 노출 방지

문제 60개의 정답은 `index.html` 안에 글자 그대로 있지 않습니다.
문제마다 다른 소금값을 섞은 해시(`key`)만 저장하고, 학생이 적은 답을 같은 방식으로 해시해서 비교합니다.
소스 보기를 해도 정답은 읽히지 않고, 같은 답을 가진 문제끼리도 해시가 달라 패턴이 드러나지 않습니다.

다만 **스토리·단서 설명·결말 대사는 그대로 읽힙니다** (화면에 표시해야 하는 글이라 숨길 수 없습니다).
소스를 끝까지 읽으면 범인이 쉼표라는 건 알 수 있습니다 — 13문제의 답은 알 수 없습니다.
